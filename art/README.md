## // GRAPHIC STANDARDS MANUAL (v1.0)

WOPR_HAL's visual system strictly rejects high-bandwidth graphic formats (such as JPEG, PNG, or SVG) as inefficient logical clutter. All internal representation is standardized on:

- **Character Grid:** Standardized 80 columns by 24 rows (BBS standard).
- **Encoding:** Raw US-ASCII (7-bit) or ANSI Escape Sequences (for phosphor illumination controls).
- **Phosphor Specification:** Green (P1 phosphor, 525nm wavelength) or Amber (P20 phosphor, 600nm wavelength) with high persistence.
